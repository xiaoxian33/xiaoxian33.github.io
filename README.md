## 📖 这是什么

一个介绍我自己的个人网站。左边是导航条，点一下就能切换页面；进来第一眼看到的是「关于我」。

## 🧭 导航

| 页面 | 里面有什么 |
| --- | --- |
| 🧑 关于我 | 进站第一眼看到的自我介绍 |
| ❤️ 兴趣爱好 | 我平时喜欢的东西 |
| 🛠️ 专业技能 | 我会的技术 |
| 📁 做过的项目 | 我做过的、正在做的项目 |
| ✍️ 发帖 | 我发的动态和心得 |
| 🤖 AI 分身 | 一个会替我回答问题的聊天窗口 |

## ✨ 目前的两个亮点

1. **✍️ 发帖** —— 像发动态一样记录，只有站长能发，访客只读。
2. **🤖 AI 分身** —— 问它关于我的事，它替我回答。

> 功能会一个一个加上来，这个站也一样。

## 🛠️ 技术栈（计划）

| 层 | 技术 |
| --- | --- |
| 后端 | Java 17 · Spring Boot |
| 页面 | Thymeleaf（服务端渲染） |
| 数据库 | MySQL |
| 前端 | 原生 HTML / CSS / JS |

## 🤖 开发方式

本项目用 **Vibe Coding** 的方式开发：

- 我负责提需求、看效果、做判断；
- **DeepSeek V4 Flash** 辅助完成代码。
