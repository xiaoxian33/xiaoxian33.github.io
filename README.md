## ✨ 这是什么

一个**数据驱动的个人网站**。外壳是一台复古像素电脑（开机自检 → 桌面 → 可拖拽窗口），里面装着：

- 📁 **作品集**：每个项目都是一张卡片，点开是它的「成长故事」——想解决什么、踩了什么坑、后来怎么升级的。
- 🧬 **技能树**：已点亮 / 修炼中 / 未解锁三态，每项技能都挂着作品证据。
- 🗺️ **未探索地图**：还没建好的区域以灰雾呈现，鼠标移上去能看到我在打什么算盘。
- 📜 **更新日志**：把自己当成一个持续发版的产品，每一次真本事的长进都记一笔。
- 👤 **AI 分身**：一个会替我回几句话的窗口（当前是「照本宣科」的规则版，以后会被换成真正会说话的我）。
- 🔐 **隐藏管理模式**：只有作者能叫出来的终端。访客在页面上**看不到任何登录入口**。

## 🌱 核心亮点

| # | 亮点 | 说明 |
|---|---|---|
| ① | **作弊码式隐藏管理端** | PC 端敲组合键唤出像素终端，静默输入主人密钥后同页变身编辑态；输错也静默失败，访客根本意识不到这里有个后台 |
| ② | **桌面 OS 外壳** | 首页不是网页，是一台电脑：开机自检动画 + 窗口系统，天然适合「无限扩充」 |
| ③ | **数据驱动无限扩充** | 新增一个作品 = 往 `data/projects/` 丢一个 JSON + 跑一条索引命令，页面结构永不需要修改 |
| ④ | **作品讲"成长故事"** | 不摆成品照，而是展示「想解决什么 → 踩了什么坑 → 怎么升级的」 |
| ⑤ | **把自己当产品发版** | 版本号 + Changelog，记录真实的成长轨迹 |

> 关于隐藏管理端的设计（以及为什么"隐蔽"不能当安全用），写在 [docs/SECRET-ENTRY.md](docs/SECRET-ENTRY.md)。

## 🚀 本地运行

浏览器会拦截 `file://` 下的数据读取，所以开发时请用本地服务器：

```bash
# 方式一：Windows 直接双击
start.bat

# 方式二：Python
python -m http.server 8080

# 方式三：Node
npx --yes serve -l 8080 .
```

然后打开 **http://localhost:8080**。

## ➕ 怎么扩充它（重要）

- **加一个作品**：在 `data/projects/` 里新建一个 JSON（照着 `cyber-tunnel.json` 抄），然后执行：
  ```bash
  node tools/index-projects.mjs
  ```
  刷新页面，桌面上就多了一个作品。
- **点亮一个技能**：改 `data/skills.json`，把 `level` 从 `learning` 改成 `lit`。
- **解锁一片地图**：改 `data/roadmap.json` 里的 `status`。
- **发一次版**：往 `data/changelog.json` 的 `entries` 里加一条。
- **加一个新窗口模块**：在 `assets/js/views.js` 里写一个视图，再到 `assets/js/os.js` 的 `APPS` 里登记一行。
